Option A — Design Decisions

Card
Rate badge → top-left
Eye enters top-left (LTR). Rate is seen early without competing with the face, which stays dominant.
Card
Name is the anchor, role secondary
Hirers identify candidates by name first, then confirm role fit. Old layout made role and name equal weight.
Card
Hover reveals "Quick Preview →"
Explicit affordance for clicking. The label bridges card → modal, reducing surprise on open.
Card
AI score chip top-right
Quality signal visible in the grid before the user clicks. Amber colour flags it as a score, not a category tag.
Modal
Left panel → video resume player
RemoteRecruit's core differentiator is video resumes. Showing the same static photo twice added no new information. Video panel gives the modal a distinct job.
Modal
Small avatar reuses same face
Continuity: user recognised the face on the card. Avatar beside the name confirms "same person" without disorientation.
Modal
AI Score as filled bar, not badge
A badge "72" had no context. A filled bar gives instant proportional understanding of high vs low.
Modal
CTAs stacked, Message full-width
Message is the primary conversion goal. Equal side-by-side splits attention. Stacking signals priority without hiding View Profile.
Modal
Rate: label above value
Label → value = natural reading order. Previous layout had value first, requiring the eye to backtrack.
